# 机械臂运动学

## 坐标系

- 右手系；`x` 指向车体前方，`z` 竖直向上，`y` 由右手系确定（车体左方）。
- 坐标原点位于底盘中心、最下面 Yaw/Pitch 关节所在的基座平面。
- 因此基座高度 `h = 254.25 mm` 已经包含在坐标定义中，逆解输入的 `z=0` 就是该基座平面，不再减去 `h`。
- 四段长度为 `l1=419.9 mm`、`l2=122.95 mm`、`l3=124.0 mm`、`l4=208.12 mm`。

关节顺序为 `J1=Yaw`，`J2..J5=四个共面 Pitch`。`J6` 是夹爪开合，不参加末端位置逆解。

## 正运动学

令 `q1` 为 Yaw，`q2..q5` 为 Pitch，定义：

```text
R = l1 cos(q2)
  + l2 cos(q2+q3)
  + l3 cos(q2+q3+q4)
  + l4 cos(q2+q3+q4+q5)

Z = l1 sin(q2)
  + l2 sin(q2+q3)
  + l3 sin(q2+q3+q4)
  + l4 sin(q2+q3+q4+q5)

x = R cos(q1)
y = R sin(q1)
z = Z
```

## 逆运动学算法

末端 `l4` 要求保持水平，因此固件增加约束：

```text
q2 + q3 + q4 + q5 = 0
```

这里的 `0` 表示 `l4` 沿基座 `+x` 方向水平；如果机械结构要求朝向 `-x`，将目标姿态改为 `pi`。位置命令仍只有 `x,y,z`，四个 Pitch 角在该姿态约束下还剩一个冗余自由度。固件使用适合 STM32F407 的阻尼最小二乘（Damped Least Squares, DLS）迭代：

1. `q1 = atan2(y,x)`，将三维目标解耦为水平距离 `R=sqrt(x²+y²)` 和平面高度 `z`。
2. 对 `q2..q5` 使用 `R、Z、末端 Pitch` 三个任务量和 `3x4` 平面雅可比矩阵。
3. 用 `J# = Jᵀ(JJᵀ+λ²I)^-1` 计算主任务步长，`λ` 在接近奇异姿态时保持数值稳定。
4. 用零空间项偏向首选姿态，并在关节接近上下限时推向关节中部。
5. 对每步做步长限制、关节限位和简单回溯，目标误差超过容差时返回不可达，不发送不完整的运动目标。

实现文件：`App/Inc/arm_kinematics.h`、`App/Src/arm_kinematics.c`。

初始软件限位（以编码器中位为软件零位）暂定为：

| 关节 | 下限 | 上限 |
| --- | ---: | ---: |
| J1 Yaw | -170° | +170° |
| J2 Pitch | -90° | +90° |
| J3 Pitch | -150° | +150° |
| J4 Pitch | -150° | +150° |
| J5 Pitch | -180° | +180° |

这些是保守的上电调试默认值，不等于实际机械限位。第一次带动力测试前，必须根据连杆干涉、线缆旋转范围和电机减速器限制重新测量；实际项目只需修改 `arm_kinematics_config_default()` 中的配置。

调用时应将 `seed_rad` 设为当前实际或最近一次有效的关节角。若需要“最小运动量”，将首选姿态设为当前姿态；若需要固定抓取姿态，则将首选姿态设为该姿态。

当前模块已经接入主工程：`arm_nuc_protocol.c` 解析 NUC 的 `PXYZ`，`arm_controller.c` 调用逆解并通过固定 ID 11..16 下发六个位置命令，J6 由 `JZH` 和力传感器闭环停止。本提交按六个电机统一旋向、编码器中位和既定机械限位配置；统一方向由 `APP_ARM_DIRECTION` 集中配置。若更换电机或机械安装，再重新确认零点、限位和 J6 开合位置。
